# Keybindings

Existing Hyprland keybindings preserved.

| Binding | Action |
| --- | --- |
| `SUPER T` | Open terminal fallback chain |
| `SUPER B` | Open blank browser page |
| `SUPER F` | Open file manager fallback chain |
| `SUPER W` | Kill active window |
| `SUPER V` | Toggle floating |
| `SUPER SHIFT T` | Toggle split layout |
| `SUPER SPACE` | Open Rofi drun |
| `SUPER SHIFT B` | Toggle Waybar |
| `SUPER H/J/K/L` | Move focus left/down/up/right |
| `SUPER SHIFT H/J/K/L` | Move window left/down/up/right |
| `SUPER P` | Region screenshot to `~/Pictures/Screenshots` |
| `XF86Display` | Cycle monitor |
| `XF86Launch1` | Run `hyprlock` if installed |
| `SUPER 1..9` | Switch workspace 1..9 |
| `SUPER SHIFT 1..9` | Move active window to workspace 1..9 |
| `SUPER S` | Toggle special workspace `magic` |
| `SUPER SHIFT S` | Move active window to special workspace `magic` |
| `SUPER mouse_down/mouse_up` | Cycle workspaces |
| `SUPER left-click drag` | Move window |
| `SUPER right-click drag` | Resize window |
| `XF86AudioRaiseVolume` | Raise sink volume 5% |
| `XF86AudioLowerVolume` | Lower sink volume 5% |
| `XF86AudioMute` | Toggle sink mute |
| `XF86AudioMicMute` | Toggle source mute |
| `XF86MonBrightnessUp` | Raise brightness 10% |
| `XF86MonBrightnessDown` | Lower brightness 10% |
| `XF86AudioNext` | Next media |
| `XF86AudioPause` | Play/pause media |
| `XF86AudioPlay` | Play/pause media |
| `XF86AudioPrev` | Previous media |
